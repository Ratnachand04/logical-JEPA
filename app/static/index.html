Logical-JEPA

Multi-scale contextual latent prediction for logical anomaly detection

Hide a region

A sliding window blanks one region of the patch grid. Every region takes its turn, so a defect can never hide inside the context.

→
2

Predict its latent

The context encoder sees only the visible patches. The predictor imagines the embedding that should be in the hidden region.

→
3

Compare

The EMA target encoder reports what is actually there. Cosine distance between the two is the anomaly score for that region.

→
4

Accumulate

Errors from every window and every scale fuse into a 16×16 grid, then upsample to a full-resolution heatmap.

Trained only on normal images. A missing, extra, misplaced or miscounted component produces a large discrepancy because the surrounding structure implies something else belongs there — which is why this catches logical errors that a texture-based detector cannot see.

Per-scale evidence

Each sweep window asks a different question. Small windows notice local texture faults; large windows notice that a whole component is wrong, missing or duplicated. Comparing the columns tells you which kind of anomaly fired.

Model card

Logical-JEPA — trained from scratch in PyTorch, no pretrained backbone. Unsupervised: only normal images are ever used for training and calibration.
